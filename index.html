توسعه‌دهندگانDEVELOPERS

یک API، همهٔ مدل‌هاOne API, every model

درگاه ابتکار با قالب Anthropic Messages کار می‌کند؛ SDKهای رسمی را بدون تغییر استفاده کنید و فقط آدرس پایه و کلید را عوض کنید.The Ebtekar gateway speaks the Anthropic Messages format. Use the official SDKs as they are; just change the base URL and the key.

BASEhttps://ebtekarai.ir/api/developer-gateway
GET/v1/modelsفهرست مدل‌هاlist models
POST/v1/messagesارسال پیام · استریمmessages · streaming
POST/v1/messages/count_tokensشمارش توکنcount tokens
ساخت کلید APICreate an API key مستندات کاملFull docs 
import os, anthropic

client = anthropic.Anthropic(
    api_key=os.environ["EBTEKAR_API_KEY"],
    base_url="https://ebtekarai.ir/api/developer-gateway",
)

msg = client.messages.create(
    model="ebtekar-smart",
    max_tokens=1024,
    messages=[{"role": "user", "content": "سلام"}],
)
print(msg.content[0].text)
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic({
  apiKey: process.env.EBTEKAR_API_KEY,
  baseURL: "https://ebtekarai.ir/api/developer-gateway",
});

const stream = await client.messages.stream({
  model: "ebtekar-smart",
  max_tokens: 1024,
  messages: [{ role: "user", content: "سلام" }],
});
for await (const e of stream)
  if (e.type === "content_block_delta") process.stdout.write(e.delta.text ?? "");
curl https://ebtekarai.ir/api/developer-gateway/v1/messages \
  -H "x-api-key: $EBTEKAR_API_KEY" \

  -H "content-type: application/json" \
  -d '{
    "model": "ebtekar-smart",
    "max_tokens": 1024,
    "messages": [{"role": "user", "content": "سلام"}]
  }'
