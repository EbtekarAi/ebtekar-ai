# Security Policy · سیاست امنیتی

## Reporting a vulnerability

If you find a security issue in Ebtekar (the website, the Developer Gateway or the Windows app), please **do not open a public GitHub issue**. Report it privately through the contact options on **[ebtekarai.ir](https://ebtekarai.ir)** and include:

- what you found and where,
- steps to reproduce,
- the possible impact.

Please give us reasonable time to fix the issue before you disclose it publicly. Don't access other users' data, disrupt the service, or run automated scans that slow it down.

## گزارش آسیب‌پذیری

اگر مشکل امنیتی‌ای در ابتکار پیدا کردید (سایت، درگاه توسعه‌دهندگان یا اپ ویندوز)، لطفاً **issue عمومی در گیت‌هاب باز نکنید**. آن را به‌صورت خصوصی از راه‌های تماس در **[ebtekarai.ir](https://ebtekarai.ir)** گزارش دهید و این موارد را بنویسید:

- چه چیزی و کجا پیدا کردید،
- مراحل بازتولید،
- اثر احتمالی.

لطفاً پیش از انتشار عمومی، فرصت معقولی برای رفع مشکل بدهید. به دادهٔ کاربران دیگر دسترسی نگیرید، سرویس را مختل نکنید و اسکن خودکاری که سرویس را کند می‌کند اجرا نکنید.

</div>

## Leaked API key? · کلیدتان لو رفته؟

Revoke it immediately in **ebtekarai.ir/developers → API keys** and create a new one. Keys can't be recovered, because only a hash is stored.

<div dir="rtl">

فوراً از **ebtekarai.ir/developers ← کلیدهای API** لغوش کنید و کلید تازه بسازید. کلیدها قابل بازیابی نیستند، چون فقط هش آن‌ها ذخیره می‌شود.

</div>
